# 老年多病共存人群新发功能受损风险预测工具

本目录准备作为论文工具的 GitHub 仓库。页面使用论文冻结的 20 套 XGBoost 管线，支持中英文，在浏览器内完成计算。**12 个变量必须完整填写；本版不处理缺失值，也不提供个体 SHAP 解释。**

## 使用方式

下载完整文件夹并解压，双击 **index.html**，点击右上角“中文”，填写所有变量及基线确认后计算。无需安装 Python、Node.js 或任何建模软件，离线也可使用。不要只下载一个 HTML 文件；`assets/` 和 `models/` 必须保留在同级目录。

脚本按直接打开本地文件设计，且无需 fetch 加载模型。自动浏览器测试已经验证本地 HTTP 访问，但该浏览器工具禁止 `file://`，因此双击打开入口未在自动浏览器中实测。

“载入合成示例”会展示人工构造的病例与预测，非真实受试者。修改输入后，页面提示重新计算，避免继续使用旧结果。“下载本次结果”保存输入、完整精度概率、阈值及版本信息。

如浏览器限制本地脚本，可在本目录运行 `python -m http.server 8000 --bind 127.0.0.1`，访问 `http://127.0.0.1:8000`；Windows 也可使用 `start-local.bat`。这只是静态文件服务，不是预测后端。

## 与论文的关系

开发数据为 CHARLS 2015–2018（1,878 人），独立外部验证为 CLHLS 2014–2018（488 人）。20 个分类器及其标准化参数直接来自冻结模型，没有重新训练、调参或选择变量。完整输入经过原 MICE 流程不会改变观测值，故本版可以在不分发供体核的情况下计算同一完整输入预测。

3,587 组合成输入对照原 Python 冻结路径，最大概率差为 3.4273×10⁻⁸，风险分层全部一致，校验容差为 10⁻⁶。结果是数值容差内一致，不是任意输入逐位一致的保证。不能据此声称网页已取得新的临床验证。[验证说明](docs/validation.md)

风险阈值为 0.3034314632454784，仅分低／高两档。界面概率显示一位小数，分层使用未四舍五入的计算值。该阈值不是已确立的治疗阈值。

开发随访中位数约 36 个月、外部约 49 个月；模型预测研究随访时的结局，不能设置任意预测时间。适用者基线无 ADL 六项及 IADL 购物／做饭受损，且至少患 7 种指定慢病中的 2 种；开发年龄 ≥60 岁，外部 ≥65 岁。

## 文件说明与发布

英文 README 列明目录和模型性能；`docs/` 包含变量字典、模型说明、验证记录、论文可用性声明及简短发布清单。`models/` 仅含推理参数，`tests/` 和 `examples/` 仅含合成输入及其参考结果，没有原始数据、MICE 供体核或真实样本 ID。

公开后，在仓库 Settings → Pages 选择 main 分支根目录即可启用在线页面。实际仓库地址和网页地址要在创建成功后补入 README 与论文。本次尚未建立远程仓库、发布页面或修改原论文。

作者与许可按用户要求暂留待填写：`CITATION.cff.example` 是维护者引用模板；`LICENSE` 明确许可尚未选定。论文尚未投稿，暂无已发表论文引用或 DOI；网页中的引用栏目已隐藏。

无需等论文录用后才能发布工具。GitHub 仓库地址和 Pages 工具地址在建立与启用后即可获得，可先用于投稿稿件；论文引用待有真实发表信息后再补。软件本身也可先提供独立引用。作者署名与许可需要在公开发布时确认，论文 DOI 和 ORCID 不是前提。详细占位位置见 [占位信息说明](docs/placeholders.md)。

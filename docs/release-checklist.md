# Before public upload

This is a short checklist for one fixed paper-associated release, not an ongoing version-management programme.

- Confirm software author attribution. If a software citation is desired now, populate `CITATION.cff` for the calculator itself; ORCID and a published article DOI are optional. Keep the citation example inactive until verified.
- Confirm the licence with the authors/institution and replace the pending `LICENSE` text.
- Review the calculator and its complete-input scope; retain the measured validation evidence.
- Create the intended public repository and upload **this folder only**, not its parent database folder or `final1`.
- Enable GitHub Pages from `main` and `/(root)`, then check the real online calculator.
- Add the actual repository and Pages links after creation. They can be used in the submitted manuscript before acceptance. Add a published article citation only when one exists; it is not a prerequisite for public upload.

One fixed `v1.0.0` release is enough for the present scope. A software DOI archive is optional unless required by the selected journal. The original frozen model hash and public file hashes already provide provenance.
